# 🎬 Movie Match App

A modern web application that helps users discover movies based on their preferences using AI and cloud services.

---

## 🚀 Features

- 🔐 User authentication (Firebase)
- 🎬 Browse popular movies (TMDB API)
- 📄 View detailed movie information
- 🎯 Movie Match (AI-based recommendations) *(in progress)*
- 📧 Email & translation features *(planned)*

---

## ☁️ Cloud Services Used

- Firebase Authentication (user login & persistence)
- TMDB API (movie data)
- (Planned) OpenAI API (AI recommendations)
- (Planned) SendGrid (email service)

---

## 🛠️ Technologies

- Next.js (React framework)
- TypeScript
- TailwindCSS
- Firebase
- REST APIs
